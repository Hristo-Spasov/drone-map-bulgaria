# 🚁 Drone Zones Bulgaria

Интерактивна карта на зоните за полети на БЛС (дронове) в България.

Показва всички зони с различни нива на ограничения, на базата на данни от Главна дирекция "Гражданска въздухоплавателна администрация" (ГД ГВА).

## 📸 Функции

- 🗺️ **Интерактивна карта** — пълно мащабиране и преместване на картата на България
- 🔴 **Забранени зони** — червени кръгове и полигони (полетите са напълно забранени)
- 🟠 **Зони с изискване за разрешение** — оранжеви зони (полети само с предварително разрешение от ГД ГВА)
- 🔵 **Условни зони** — сини зони (полети са разрешени при определени условия, напр. предварително уведомяване)
- 📋 **Информация при клик** — подробности за зоната: име, причина, височина, контакт на органа
- ⚙️ **Филтри** — включване/изключване на типове зони чрез страничния панел
- 🛰️ **Сателитен изглед** — три режима на картата: улици, сателит, сателит + улици
- 📍 **Моето местоположение** — определяне на текущата позиция на потребителя
- 🔄 **Автоматично обновяване** — сървърът автоматично изтегля най-новите данни от ГД ГВА
- 📱 **PWA** — работи офлайн след първо зареждане


## 🚀 Стартиране

### Локална разработка

```bash
npm install
npm run dev
```

Картата ще бъде достъпна на `http://localhost:5173`

### Продукция

```bash
npm start
```
### Docker

```bash
docker build -t drone-zones-bulgaria .
docker run -p 3000:3000 drone-zones-bulgaria
```

## 📊 Данни

Данните се изтеглят автоматично от страницата на ГД ГВА:
`https://www.caa.bg/bg/category/633/7062`

### Типове зони

| Цвят | Тип | Описание |
|------|-----|----------|
| 🔴 Червен | PROHIBITED | Полетите са напълно забранени |
| 🟠 Оранжев | REQ_AUTHORISATION | Изисква се разрешение от ГД ГВА |
| 🔵 Син | CONDITIONAL | Полети при определени условия |
